## Git Commands Used in This Assignment
| Command | Description |
| :--- | :--- |
| `git clone` | Cloned the repository from GitHub to local machine. |
| `git config` | Configured local user name and email. |
| `git checkout -b` | Created and switched to new feature branches. |
| `git add` | Staged changes for the next commit. |
| `git commit -m` | Recorded changes with descriptive messages. |
| `git push` | Uploaded local branch commits to the remote repository. |
| `git merge` | Combined feature branches into the main branch. |
